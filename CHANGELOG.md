# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial release
- User authentication and authorization
- Content search and browsing
- Multiple provider integration (YGG, C411, TR4KER)
- Smart source selection with latency checking
- Watch history and favorites
- Docker deployment support
- PostgreSQL database with migrations
- Redis caching
- JWT authentication
- Rate limiting
- Comprehensive API documentation (OpenAPI/Swagger)
- Jest test suite with CI/CD pipeline
- GitHub Actions for automated testing and deployment
- Nginx reverse proxy with SSL support
- Error tracking with Sentry integration
- Logging with Pino
- Support for movies, TV series, and anime

### Features
- **Search**: Full-text search across all content
- **Sources**: Multiple quality options, language variants
- **Verification**: Automated link verification and latency checking
- **Caching**: Redis-based caching for performance
- **Admin Dashboard**: User and content management
- **User Preferences**: Quality, language, and theme settings
